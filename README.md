# Библиотека эксперта

Открытая методическая база для подготовки заключений по обследованию зданий и сооружений
по ГОСТ 31937-2024: термины, конструктив, каталог дефектов, методики, критерии категорий
технического состояния, шаблоны и формулировки, обоснования, справочник, мониторинг,
контроль качества.

**Открыть:** https://nekujay.github.io/expert-library/

## Что внутри

- Нормативная база: разбор ГОСТ 31937-2024 (этапы, объёмы, цифры, формы А/Б, приложения В—Д).
- Термины: определения категорий состояния и практические термины.
- Конструктив К-01…К-10: что проверять по каждому элементу и чем измерять.
- Дефекты: признаки, причины, категория, ссылка на норму.
- Методики: этапы, методы, приборы, объёмы испытаний.
- Критерии: четыре категории и пороги.
- Шаблоны: структура тома, разделы, готовые формулировки.
- Обоснования: связки «норма → вывод».
- Справочник: сортаменты, материалы, приборы, сроки службы.
- Мониторинг: виды, формы Ж/И/К/Л/М, чек-лист этапа.
- Контроль качества: приёмка заключения и типовые ошибки.

## Что не публикуется

Внутренние материалы рабочих обследований: адреса объектов, заказчики, реестр объектов
и рабочий журнал. Здесь только методическая часть.

## Источники

ГОСТ 31937-2024 «Здания и сооружения. Правила обследования и мониторинга технического
состояния»; СП 15.13330.2020, СП 16.13330.2017, СП 63.13330.2018, СП 64.13330.2017,
СП 20.13330.2016, СП 22.13330.2016; 384-ФЗ.

Материал носит методический характер и не заменяет проектную документацию и заключение
специализированной организации.
